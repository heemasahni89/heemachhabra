## Gallery inventory decision

The untouched baseline contained 69 mobile slide records and corresponding desktop/component captions. The complete baseline-derived inventory included Paris, Brussels, Uccle, Biarritz, Ramatuelle and Rhodes Saint Genèse locations; photographer/architect/collaborator credits; and the template title/subtitle pair `Galerie Jean-Jacques Dutko` / `Design Basel 2012`. None are verified HCDC project facts, so every desktop and mobile project title/subtitle hook is intentionally empty after migration. The 82 existing `h3`/`h4` hooks remain in place for animation/layout compatibility, but no unsupported caption is rendered or restored by hydration.

This is an intentional editorial state, not missing copy. When HCDC supplies approved project titles, locations, scope, credits, image rights and summaries, those hooks can be populated through the same generated-build migration with project-specific factual captions.
